Chaque fichier `.sql` de ce dossier est exécuté **une seule fois** sur la base Supabase, dans l'ordre des noms,
par l'action GitHub « Supabase » (onglet Actions). Ne jamais modifier un fichier déjà installé : en créer un nouveau.
La liste des fichiers installés est dans la table `public.hpg_migrations`.
