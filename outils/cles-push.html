Clés des notifications push

Cette page fabrique, dans votre navigateur, la paire de clés qui permet à HPG d'envoyer des notifications sur les téléphones. Rien n'est envoyé sur internet.

Gardez la clé privée secrète : ne la mettez jamais dans config.js. Générez les clés une seule fois : si vous les changez, chaque employé devra réactiver les notifications.
